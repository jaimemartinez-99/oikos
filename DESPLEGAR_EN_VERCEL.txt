DESPLIEGUE EN VERCEL

ANTES DE EMPEZAR
- Confirma que npm run build termina correctamente.
- No subas ni compartas el archivo .env. Contiene configuración del proyecto.
- El build command es: npm run build
- El directorio de salida es: dist
- vercel.json ya está incluido para que las URLs /login y /app/... funcionen al recargar.

OPCIÓN RECOMENDADA: PANEL WEB + GITHUB

1. Crea un repositorio privado en GitHub y sube este proyecto (sin .env ni node_modules).
2. En https://vercel.com, entra con GitHub y selecciona Add New > Project.
3. Importa el repositorio de Oikos.
4. Vercel detectará Vite. Verifica:
   Framework Preset: Vite
   Build Command: npm run build
   Output Directory: dist
5. En Environment Variables añade estas dos variables en Production, Preview y Development:
   VITE_SUPABASE_URL = la URL de tu proyecto Supabase
   VITE_SUPABASE_ANON_KEY = la clave anon/publishable de Supabase
   Puedes copiar ambos valores de tu .env local. La anon key es apta para navegador; NO uses service_role.
6. Pulsa Deploy. Guarda la URL final, por ejemplo: https://oikos-tu-cuenta.vercel.app

CONFIGURACIÓN OBLIGATORIA EN SUPABASE TRAS EL PRIMER DEPLOY

7. En Supabase > Authentication > URL Configuration:
   - Site URL: pega la URL final exacta de Vercel.
   - Redirect URLs: añade:
       https://oikos-tu-cuenta.vercel.app/**
       https://*-tu-cuenta.vercel.app/**   (para previews de Vercel)
8. En Supabase > Authentication > Providers > Email, mantén desactivado «Allow new users to sign up» para conservar el modelo de invitación privada.
9. Comprueba en la URL de Vercel: iniciar sesión, crear un gasto y extraer datos de un enlace de mueble.

ACTUALIZACIONES POSTERIORES
- Cada push a la rama principal despliega producción automáticamente.
- Las ramas o pull requests crean previews. Si estas usan Auth, deben estar cubiertas por el patrón Redirect URL anterior.

OPCIÓN POR TERMINAL (ALTERNATIVA)
1. npm install -g vercel
2. vercel link
3. Configura las dos variables VITE_SUPABASE_* en Vercel Dashboard > Project > Settings > Environment Variables.
4. vercel deploy --prod

SI FALLA EL BUILD
- Ejecuta npm run build localmente y corrige primero ese error.
- En Vercel > Deployments > el deployment fallido > Build Logs encontrarás el detalle.
