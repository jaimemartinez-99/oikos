ARREGLO: "infinite recursion detected in policy for relation household_members"

En Supabase > SQL Editor, ejecuta este bloque UNA VEZ. Corrige la política ya aplicada; no borra datos.

create or replace function public.is_household_owner(target_household uuid)
returns boolean
language sql
stable
security definer
set search_path = public
as $$
  select exists(
    select 1 from public.household_members
    where household_id = target_household
      and user_id = auth.uid()
      and role = 'owner'
  )
$$;

drop policy if exists "owners manage members" on public.household_members;

create policy "owners manage members"
on public.household_members
for all
using (public.is_household_owner(household_id))
with check (public.is_household_owner(household_id));

Después recarga la aplicación e inicia sesión de nuevo. El archivo supabase/schema.sql ya incluye esta corrección para instalaciones nuevas.
